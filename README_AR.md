# ECHO FX

تطبيق Flutter لأندرويد يلتقط صوت المايك ويضيف صدى مباشر مع مستوى قابل للتغيير.

## البناء عبر GitHub Actions / Kleancode

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. شغّل workflow باسم **Android APK** من تبويب Actions.
3. نزّل ملف APK من Artifacts.

الـ workflow ينشئ هيكل Android القياسي بواسطة Flutter ثم يضيف ملف Kotlin لمعالجة الصوت.

## ملاحظة تشغيل
اسمح بصلاحية المايك. استخدم سماعات؛ تشغيل الصدى على سبيكر الهاتف قد يسبب صفيراً أو تغذية راجعة صوتية.
